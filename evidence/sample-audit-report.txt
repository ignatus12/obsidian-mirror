 3. HOST METADATA NOT PROTECTED - AND WHY
----------------------------------------------------------------------------------------------------

   KNOWN LIMITATIONS - not covered, by design or by physics

   * Host /root readable (no pivot_root)  [fs.root_home]
       app sees  : 0
       reason: There is no pivot_root, so the host filesystem outside the masked paths is still
       visible, subject to normal permissions. /home is tmpfs, so user data is covered; /root,
       /var, /srv and other users' files are not. Fixing this needs a full root pivot, which
       breaks applications that read their own installation directory.

   * LD_PRELOAD visible to application  [det.ld_preload]
       app sees  : /opt/obsidian/lib/obsidian_core.so:/opt/obsidian/lib/obsidian_wayland.so:/opt/obsidian/lib/obsidian_gpu.so
       reason: LD_PRELOAD must stay set for the libc hooks to exist. Any application that reads
       /proc/self/environ can see it. Obsidian Mirror makes you anonymous, not invisible.

   * OBSIDIAN_* variables in environment  [det.obsidian_env]
       app sees  : 5
       reason: The hooks read their spoofed values from these variables, so they have to be in the
       environment.

   * /opt/obsidian visible in filesystem  [det.opt_obsidian]
       app sees  : visible
       reason: The launcher, hooks and manifest have to live somewhere the sandboxed process can
       reach.


   OUT OF SCOPE - the network layer, excluded by design

   * Network interface names  [net.interfaces]
       app sees  : eth0 lo
       reason: Network layer is out of scope by design. Pair Obsidian Mirror with a VPN or a
       network namespace.

   * NIC MAC addresses  [net.mac_addresses]
       app sees  : 02:fc:00:00:00:05
       reason: Out of scope. getifaddrs() is hooked, but anything using netlink directly (ip, ss,
       most language runtimes) sees the real MAC.

   * DNS resolver configuration  [net.resolv_conf]
       app sees  : nameserver 8.8.8.8
       reason: Out of scope: resolver identity belongs to the network layer.

   * /etc/hosts  [net.hosts_lines]
       app sees  : 8
       reason: Out of scope.


   CANNOT BE FIXED AT THIS LAYER
     * CPUID instruction: runs in userspace. Real CPU vendor, family, model, stepping and feature
     bits are readable by any program. /proc/cpuinfo is spoofed; the instruction is not. Only a
     hypervisor can mask it.
     * RDTSC and timing: clock skew, TSC frequency and boot-time correlation are physical
     properties of the machine.
     * Raw syscalls bypass LD_PRELOAD: syscall(SYS_uname) returns the real kernel release. Go
     binaries, static binaries and hand-written assembly skip libc entirely. Mount-level spoofs
     still apply to them; libc hooks do not.
     * setuid / setgid binaries: the dynamic loader drops LD_PRELOAD for them, so they run
     unhooked.
     * glibc symbol aliases: programs calling __xstat / __fxstat (gcompat, glibc containers) miss
     the stat hooks.
     * Detectability: an application can tell it is being mirrored. Obsidian Mirror makes you
     anonymous, not invisible.
